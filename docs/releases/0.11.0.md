# CLI 0.11.0 — Claude's real models, posts that commit themselves, repo pictures

This release lists the Claude models your Claude Code actually runs, commits each local post the CLI writes, and returns a repo's identity image. It also makes reply ids easier to give and corrects the command catalog.

## What changes

**`claude-status` and `claude-models` list what Claude Code reports.** For each alias (`opus`, `sonnet`, `haiku`, `fable`, `opusplan` and the default), the CLI reads the model id from Claude Code's own `system/init`, with the run stopped there: no model call and no saved session. A new Claude model now shows up the day Claude Code resolves an alias to it, with no CLI release. Each JSON row carries `ref` (the alias) and `reported: true` when the id came from the binary. (#332)

**`threads post` and `threads close` commit the post they write.** That one file, as its own commit, under the repository's own Git identity. Anything else staged stays staged, and nothing is pushed. `--no-commit` skips the commit, for tests and dry runs. A commit that can't be made (a hook, a lock, no identity, no repository) never loses the post: the command exits 0 and says `Written, not committed: <reason>`. `--json` carries `committed`, with `commit` (the sha) or `reason`. Hosted posts are unchanged, and `threads new`, `attach` and `init` don't commit yet. (#337)

**A repo's picture travels with it.** `image: _assets/<file>` in a root `README.md` (PNG, JPEG or WebP, at most 256 KiB, inside the repo) is the repo's identity image, as the protocol specifies. `look <repo>` shows it and its JSON carries `target.image`. `map <file.map.md> --json` gives each root `image`, or `null` with `image_problem` when a declared image fails a check. A bad image never fails the read. SVG isn't accepted yet. (#336)

**Smaller fixes**
- A local `--reply-to` takes a post's eight-hex short form (`msg_1b7f2056`) when only one post in the Thread starts with it. A short form two posts share is refused, naming both full ids. (#333)
- `look` paging flags imply `--depth children`, and `--post` implies `--depth full`. Each paged post shows its id. (#333)
- The command catalog describes only what runs: `look` no longer lists `--new`, which it refuses, and its evidence guidance is corrected. (#334, #335)

## Installing

```sh
npm install -g @ideaspaces/cli@0.11.0
```

The CLI needs Node 20 or newer. The Claude plugin, Pi package and Desktop carry their own CLI pins; installing this npm release does not update them.
