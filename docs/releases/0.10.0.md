# CLI 0.10.0 — a command catalog, Thread owners and dates, honest pages

This release lets an agent ask the CLI what it can do, tells you who owns a Thread and when it moved, and fixes Thread pages that looked complete when they were not.

## What changes

**Ask the installed CLI what it can do.**

- `capabilities --json` lists fourteen groups, each with a `use_when` line. `capabilities threads --json` lists a group's commands briefly, and `capabilities threads.post --json` gives one command's full contract: flags, input, output, and what it needs. Job ids also select groups.
- The catalog describes contracts only. It never says which host exposes a command or what a host permits. It ships in the bundle as `bundle/agent-tools.json` with its JSON Schema.

**`threads list --json` carries ownership and dates.** Each local row adds `attached_to` (`null` when unattached), `owner` with `owner_source`, `first_post_at` and `newest_post_at`. The owner is the README's named holder (`owner:` or `holder:` in its frontmatter, `Held by <name>` in its summary, or a `Holder:`/`Owner:` line), else the author of the opening post. Existing fields are unchanged. `newest_post_at` equals `latest_activity_at`.

**Thread pages tell the truth.**

- A capped `threads open --depth summary` page shows `N of M` and the cursor to continue, folds mark text onto the post it marks, and acknowledges marks along with posts.
- Numbered `Goal` and `Done when` headings are read.
- `--help` prints to stdout, each verb prints its own usage, and an invented verb in a group fails on stderr instead of being treated as supported.

**Snapshots carry a Map, and Map moments are searchable.**

- `threads post --kind snapshot` without `--map <note>` refuses before writing anything; a deliberately empty Map is valid. Old Map-less snapshots still read, with a `snapshot_requires_map` warning.
- `search has:map` finds readable Maps on any record. `has:map kind:post` finds Map-carrying moments across local Threads, and `in:_threads/<slug>` limits it to one. `post-kind:snapshot` filters by kind.

## Coming from 0.9.1 or earlier

Nothing is removed. A script that reads `threads list --json` sees extra keys. A script that posts a snapshot without `--map` now fails with guidance. `0.9.2` was never published; its changes are in this release.

## Installing

```sh
npm install -g @ideaspaces/cli@0.10.0
```

The CLI needs Node 20 or newer. The Claude plugin, Pi package and Desktop carry their own CLI pins; installing this npm release does not update them. Their pin changes are separate.
