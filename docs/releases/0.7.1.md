# CLI 0.7.1 — subscription client retirement

Prepared, not published.

`follow` and `unfollow`, including subscription `follow --ack`, are retired.
Old invocations exit 1 with an actionable message and send no request or read
credentials. General help no longer advertises them; command-specific help
explains the retirement. The subscription API helpers are removed.

Use `threads list --unread` for unread Threads. A person can explicitly mark a
Thread read with `threads ack <id> --cursor <cursor>`; agent tools do not do this.
This does not replace follows with a new subscription design or change the server.
